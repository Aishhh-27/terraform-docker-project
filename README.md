# 🚀 Terraform Docker Project

## 📌 Overview
This project uses Terraform to automate Docker containers:
- Flask app
- PostgreSQL database
- Docker network
- Persistent volume

---

## 🏗 Architecture
User → Flask App → PostgreSQL

---

## 🛠 Tech Stack
- Terraform
- Docker
- Flask
- PostgreSQL

---

## 🚀 Run Project

terraform init  
terraform apply  

---

## 🌐 Output
http://localhost:8080  

---

## 💣 Destroy
terraform destroy  

---

## ✅ Output
Connected to PostgreSQL
